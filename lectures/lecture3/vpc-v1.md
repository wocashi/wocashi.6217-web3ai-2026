# VPC v1

![VPC v1](../../assets/vpc-v1.png)

## 1. 顧客の仕事 (Customer Jobs)
- 毎日学習を継続できている
- 英語への苦手意識が減っている
- 英語の記事を読める
- TOEIC点数を伸ばしたい
- 英語の基本例題がスラスラ言えるようになりたい

## 2. 悩み (Pains)
- 何を勉強すればいいかわからない
- 毎日やる習慣がない
- 成長を感じにくい
- 単語をすぐ忘れる
- 勉強が楽しくない
- TOEIC教材が多すぎる
- 忘れてしまう
- モチベーションが保てない

## 3. 利得 (Gains)
- 英語学習が日常化している
- 英語を見る抵抗感が減る
- 小さい成功体験を積める
- 学習記録が見えて自信になる
- 英語圏のスタンドアップコメディで笑える
- 発音がきれいになり、伝わる英語になる

## 4. 悩み解消 (Pain Relievers)
- AIが毎日の学習内容を自動提案する
- 忘却タイミングで復習通知を送る
- 小さい達成を可視化する
- 誰かと勉強の共有ができる

## 5. 利得創出 (Gain Creators)
- 毎日続けられる設計にする
- 英語を使う楽しさを体験させる
- 発音改善をリアルタイムで支援する
- 英語学習を通じて友達を作れる

## 6. 製品・サービス (Products & Services)
- AI英語コーチ
- 毎日5分だけ出題するアプリ
- 忘却曲線に合わせた復習システム
- ゲーム感覚の英語学習アプリ
- 発音を音声学に基づいて指摘してくれる機能
- 文法を簡単にかみ砕いて説明してくれるアプリ
